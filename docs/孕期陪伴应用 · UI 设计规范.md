# 孕期陪伴应用 · UI 设计规范

版本 v0.1 · 2026-11-16 · 配套《孕期陪伴应用 · 架构设计文档》 · 状态：草稿

## 1. 目的与适用范围

本规范约定应用的视觉与交互标准，覆盖两个界面：**录入端**（我使用，手机为主）和**只读查看端**（家人使用，只看不改）。目标是让界面平静、温暖、好上手，并在医院现场、弱光、单手操作等场景下依然好用。

## 2. 设计原则

1. **平静优先**：长期使用，且常带着一点紧张的场景，界面不制造焦虑，不用刺眼颜色和警告式语气
2. **录入要快**：常用操作 1～2 次点击完成，默认值预填，能选就不打字
3. **查看要安心**：只读页信息少、留白多，把「下一步是什么」放在最前面
4. **克制**：一个页面只有一个主按钮，一种强调色，不堆装饰
5. **不单靠颜色**：任何状态都配图标或文字
6. **不做诊断**：界面只呈现与提醒，判断留给医生

## 3. 色彩系统

### 3.1 亮色主题

主方案采用薰衣草紫、蜜桃色和暖白底。

| 令牌 | 色值 | 用途 |
| --- | --- | --- |
| --color-primary | #6D5FA3 | 主按钮、选中态、链接、孕周卡底色 |
| --color-primary-soft | #EFEBF8 | 选中背景、参考范围带、次级强调底 |
| --color-on-primary | #FFFFFF | 主色上的文字 |
| --color-accent | #F4A58A | 点缀：里程碑、倒计时标签；不作文字色 |
| --color-accent-soft | #FDEEE7 | 「下次产检」等情感类卡片底 |
| --color-on-accent | #5A2F20 | 点缀色底上的文字 |
| --color-on-accent-soft | #7A3F28 | 点缀浅底上的文字 |
| --color-bg | #FAF7F5 | 页面底（暖白） |
| --color-surface | #FFFFFF | 卡片、输入框 |
| --color-border | #E8E2DC | 分割线、卡片描边 |
| --color-border-strong | #91867E | 输入框、次按钮描边 |
| --color-text | #2B2830 | 正文 |
| --color-text-secondary | #6B6573 | 说明、辅助信息 |

配色比例参考：中性色约 80%，主色约 10%，点缀色约 10%。

### 3.2 状态色

| 状态 | 圆点/图标 | 底色 | 文字 | 用于 |
| --- | --- | --- | --- | --- |
| 正常 / 已完成 | #3F8F68 | #E6F3EC | #2F6F4E | 已打卡、数值在参考范围内 |
| 需关注 / 待处理 | #A86E12 | #FFF2D9 | #8A5A0B | 待打卡、数值超出参考范围、待问医生的问题 |
| 删除 / 不可撤销 | #B83A3A | #FBE7E5 | #9E2F2F | 仅用于删除、清空等不可逆操作 |

规则：

- 数值超出报告参考范围时用「需关注」，不用红色，并附一句说明，如「下次产检时问问医生」
- 状态标签一律「圆点/图标 + 文字」，不单靠颜色区分
- 危险按钮的实心底色为 #B83A3A，白字，只出现在确认弹层中

### 3.3 暗色主题

暗色不是简单反色：背景带一点紫调，主色提亮，状态色降低饱和度。

| 令牌 | 暗色值 | 令牌 | 暗色值 |
| --- | --- | --- | --- |
| --color-bg | #1F1D24 | --color-primary | #A99BE0 |
| --color-surface | #28252F | --color-primary-soft | #3A3358 |
| --color-border | #3D3947 | --color-on-primary | #1F1D24 |
| --color-border-strong | #797487 | --color-accent | #F0A58B |
| --color-text | #ECE8F2 | --color-accent-soft | #3B2A26 |
| --color-text-secondary | #A8A2B3 | --color-on-accent | #2A1A14 |
| 成功 点/底/字 | #6FC49A / #1E3329 / #9BDDBC | --color-on-accent-soft | #F6CBB9 |
| 需关注 点/底/字 | #E5B25D / #3A2F18 / #F0CB85 | 危险 点/底/字 | #E57B7B / #3B2022 / #F0A3A3 |

默认跟随系统。设置页可通过根元素的 `data-theme="light"` 或 `data-theme="dark"` 切换，移除此属性即可恢复跟随系统。旧浏览器不支持 `light-dark()` 时使用亮色主题。设置页入口待实现。

| 按钮文字 / 主色按下态 | 6.71:1 | 5.25:1 | 文字 ≥ 4.5:1 |
| 主色字 / 主色浅底 | 4.69:1 | 4.71:1 | 文字 ≥ 4.5:1 |
| 正文 / 页面底 | 13.59:1 | 13.81:1 | 文字 ≥ 4.5:1 |
| 次要文字 / 页面底 | 5.27:1 | 6.74:1 | 文字 ≥ 4.5:1 |
| 点缀文字 / 点缀色 | 5.69:1 | 8.33:1 | 文字 ≥ 4.5:1 |
| 点缀浅底文字 / 点缀浅底 | 7.22:1 | 9.17:1 | 文字 ≥ 4.5:1 |
| 状态文字 / 状态底 | 5.25～6.09:1 | 7.40～8.63:1 | 文字 ≥ 4.5:1 |
| 状态圆点 / 状态底 | 3.44～4.77:1 | 5.26～6.79:1 | 图形元素 ≥ 3:1 |

### 3.5 图表配色

- 序列色：主色、深蜜桃 #CB5D3D、中性灰 #6B6573，最多三条线
- 多条曲线同时用线型（实线/虚线）和标记形状区分，不单靠颜色
- 参考范围用主色浅色带表示，不用红色；超出范围的点加「需关注」图标
- 网格线 #EFEAE4，细线；轴文字 12px，次要文字色
- 暗色模式下序列色改为 #A99BE0、#F0A58B、#A8A2B3

### 3.6 设计令牌（CSS）

两套主题和圆角令牌集中维护在 [tokens.css](../frontend/src/styles/tokens.css)。录入端和只读端共用该文件。组件按用途引用令牌，同一组底色和文字色成对使用。

图表集成时，从实际应用了令牌的 CSS 属性读取计算后的颜色值，并在主题变化时刷新图表。这样图表库拿到的是当前主题下的具体颜色。

## 4. 字体与排版

使用系统字体，不加载网络字体：

```css
font-family: 'HarmonyOS Sans SC', 'PingFang SC', 'Noto Sans SC', 'Microsoft YaHei', system-ui, sans-serif;
```

只使用两种字重：常规 400、中等 500。字号用 rem，尊重系统字体缩放。

| 层级 | 字号 | 字重 | 行高 | 用途 |
| --- | --- | --- | --- | --- |
| 大数字 | 28px | 500 | 1.2 | 孕周、倒计时 |
| 页面标题 | 22px | 500 | 1.3 | 页面顶部 |
| 区块标题 | 17px | 500 | 1.4 | 卡片、分组标题 |
| 指标数值 | 20px | 500 | 1.3 | 体重、血压等，启用等宽数字 tabular-nums |
| 正文 | 16px | 400 | 1.6 | 大部分内容 |
| 说明 | 14px | 400 | 1.5 | 辅助信息、表单标签 |
| 标注 | 12px | 400 | 1.4 | 导航文字、图表轴；不得小于 12px |

## 5. 间距、圆角与层次

- **间距**：以 4px 为基准，常用 4 / 8 / 12 / 16 / 24 / 32；页面左右边距手机 16px、≥ 640px 为 24px；卡片间距 12px，区块间距 24px
- **圆角**：小标签 8px，按钮与输入框 12px，卡片 16px，药丸标签 999px
- **层次**：不使用阴影，卡片靠 1px 描边或底色区分；弹层才使用遮罩
- **边框**：默认 1px `--color-border`，输入框 1px `--color-border-strong`，聚焦 2px 主色

## 6. 布局与响应式

| 断点 | 布局 |
| --- | --- |
| < 640px | 单列，底部导航，卡片通栏 |
| 640～1023px | 卡片双列，底部导航 |
| ≥ 1024px | 左侧导航，内容最大宽度 960px |

- 移动端优先，**触控目标不小于 44×44px**
- 主操作按钮放在屏幕下半部，便于单手拇指操作；表单页底部固定主按钮
- 适配刘海与手势条：使用安全区内边距（safe-area-inset）
- 只读查看端始终单列，最大宽度 560px 居中，不随屏幕变复杂

## 7. 组件规范

### 7.1 按钮

| 类型 | 样式 | 使用 |
| --- | --- | --- |
| 主按钮 | 主色底，`--color-on-primary` 文字，高 48px，圆角 12px | 每页最多一个 |
| 次按钮 | `--color-surface` 底，1px border-strong，主色文字 | 并列的次要操作 |
| 文字按钮 | 无底，主色文字 | 低优先级、行内操作 |
| 危险按钮 | #B83A3A 底，白字 | 仅在删除确认弹层中 |

- 状态：按下加深约 12%；聚焦显示 2px 主色环并外扩 2px
- 尽量不使用禁用按钮：保持可点击，点击后提示还缺什么
- 按钮文字用动词开头，1～4 个字，如「保存产检记录」「添加」「取消」

### 7.2 输入框与表单

- 高 48px，标签在输入框上方（14px），不使用仅占位符的标签
- 数值输入唤起数字键盘，带单位后缀（kg、mmHg、cm），体重等常用项带 ± 步进
- 预填上次的单位，并在输入框下提示「上次 58.2 kg」，方便对照
- 输入校验用顶部提示横幅说明如何修改，焦点回到第一个无效字段
- 表单自动保存草稿，意外退出不丢数据

### 7.3 卡片

| 卡片 | 规格 |
| --- | --- |
| 孕周卡 | 主色底，`--color-on-primary` 文字，圆角 16px，内边距 16～20px，大数字显示「孕 24 周 3 天」，下方一行倒计时 |
| 下次产检卡 | 点缀浅底，左侧日历图标，右侧药丸标签显示「15 天后」 |
| 信息卡 | `--color-surface` 底，1px 描边，圆角 16px，内边距 16px |
| 指标卡 | 指标名 + 数值（20px）+ 状态标签；点击进入趋势 |

### 7.4 标签（Pill）

高 24～28px，圆角 999px，左侧 8px 圆点或图标 + 文字，12～14px；颜色取 3.2 的状态色三件套。

### 7.5 导航

- 录入端底部导航四项：**今天 / 产检 / 记录 / 更多**，图标 24px + 12px 文字，选中为主色加 500 字重，高 56px 加安全区
- 查看端不设导航，页面自上而下滚动，顶部只有标题

### 7.6 弹层、提示与空状态

- **底部抽屉**：用于选择与确认，上圆角 16px，带拖动条；不叠加两层弹层
- **确认删除**：使用顶部确认横幅，提供「取消」与「确认删除」按钮，等待用户选择
- **提示横幅**：成功、失败、校验与操作说明统一在页面顶部浮动显示。成功提示显示 4 秒，其余显示 8 秒，均可手动关闭
- **空状态**：线性图标（次要色）+ 一句话 + 一个动作，如「还没有产检记录」「记下第一次产检，之后就能在这里看到变化」，按钮「添加产检」

### 7.7 图表

折线宽 2px，数据点 4px，当前点放大；参考范围带用主色浅色；提示框显示日期、孕周与数值；横轴同时支持「孕周」与「日期」切换，默认孕周。

## 8. 页面级规范

### 8.1 录入端 · 今天

1. 孕周卡（孕周 + 天、距预产期天数）
2. 下次产检卡
3. 今日待办：补剂打卡、待问医生的问题数
4. 快捷记录四宫格：饮食 / 症状 / 补剂 / 备注
5. 最近记录时间线（最近 3 条）

### 8.2 录入端 · 产检录入

单页分组，自上而下：基本信息（日期、医院、医生，预填上次）→ 指标（常用指标网格，可添加）→ 附件（拍照上传）→ 医嘱与小结 → 下次预约 → 查看者设置（是否对家人可见、写给家人的说明）。底部固定主按钮「保存产检记录」，草稿自动保存。

### 8.3 录入端 · 每日记录

顶部日期切换条；三餐与加餐卡片（拍照 + 一句话）；症状标签可多选的 chips；补剂清单一点即打卡；备注支持文字与语音。

### 8.4 趋势页

顶部指标 chips 可横向滚动；折线图 + 参考范围带；下方按产检列出数值，最近的在前。

### 8.5 查看端首页

孕周卡 → 下次产检卡 → 最近一次产检摘要（优先显示「写给家人的说明」，不展示原始医嘱）→ 趋势入口 → 可见记录时间线。页面无任何编辑控件，页脚一行小字「由家人记录」。

## 9. 交互与动效

- 动效克制：悬停与按下 150ms，元素出现 200ms，抽屉 250ms，缓动统一用 ease-out
- 尊重系统「减少动态效果」设置，开启时关闭位移与缩放动画
- 数字不做滚动动画，避免干扰
- 保存采用即时反馈（Toast），弱网时进入待同步队列，并在顶部显示轻提示「已离线保存，联网后自动同步」
- 列表与表单保留上次的选择（医院、单位、常用指标顺序）

## 10. 文案与语气

语气温和、简短、像家人之间说话，使用「你」，不使用感叹号和医学化的警告词。

| 场景 | 不建议 | 建议 |
| --- | --- | --- |
| 数值超出范围 | 警告：数值异常！ | 这个数值超出报告参考范围，下次产检时问问医生 |
| 保存成功 | 您的记录已成功保存！ | 已保存 |
| 删除确认 | 确定要永久删除吗？ | 删除这条产检记录？删除后无法恢复。 |
| 空状态 | 暂无数据 | 还没有产检记录，记下第一次产检吧 |
| 离线 | 网络错误 | 已离线保存，联网后自动同步 |

格式约定：

- 孕周：「孕 24 周 3 天」；倒计时：「距预产期还有 109 天」
- 日期时间：「12 月 1 日 周二 09:30」，跨年时补年份
- 数值：数字与单位间留一个空格，如「58.2 kg」「118/76 mmHg」，小数位以报告为准
- 按钮与标签不加句号，说明文字句末加句号

## 11. 图标与插画

- 使用线性图标库（如 Lucide 或 Tabler，均为开源），默认 24px，描边风格统一，颜色继承文字色
- 图标不单独表意，旁边配文字，纯图标按钮需有可访问名称
- 插画可选，风格轻、扁平、不拟人化，仅用于空状态与引导，不放在数据页

## 12. 可访问性

- 文字对比度 ≥ 4.5:1，图形元素 ≥ 3:1（见 3.4）
- 状态不单靠颜色；图表用线型与标记辅助区分
- 字号用 rem，系统字体放大到 200% 时布局不破
- 所有可交互元素有可见的聚焦样式，支持键盘操作
- 图标按钮、图表、图片有文字说明（aria-label / alt）
- 触控目标不小于 44×44px，相邻目标间距不小于 8px

## 13. 与日历及分享的视觉约定

- 手机系统日历中订阅的「孕期日程」日历，建议在本机把颜色设为主色 #6D5FA3，与应用一致
- 日历事件标题保持通用（如「产检」「补剂」），不含指标与医嘱（见架构文档 10.2）
- 分享的只读链接页面沿用本规范色板，但饱和度更低、留白更多，视觉上区别于录入端

## 14. 备选方案与待定事项
